# Estruturas Condicionais em Python

## Visão geral

Estruturas condicionais permitem **desviar o fluxo de execução** do programa com base em expressões que resultam em `True` ou `False`.

As principais estruturas são:

- `if`;
- `if / else`;
- `if / elif / else`;
- `if` aninhado;
- `if` ternário.

> Python utiliza **indentação** para definir quais instruções pertencem a cada bloco condicional.

---

## 1. `if`

O `if` executa um bloco de código **somente quando a condição for verdadeira**.

### Sintaxe

```python
if condição:
    # Código executado se a condição for True
```

### Exemplo

```python
saldo = 500
saque = 200

if saldo >= saque:
    print("Saque realizado com sucesso!")
```

Se `saldo >= saque` for `True`, a mensagem será exibida. Caso contrário, o bloco será ignorado.

### Exemplo com duas condições independentes

```python
saldo = 2000.0
saque = float(input("Informe o valor do saque: "))

if saldo >= saque:
    print("Realizando saque!")

if saldo < saque:
    print("Saldo insuficiente!")
```

Nesse caso, os dois `if`s são avaliados separadamente. Como as condições são opostas, normalmente é mais adequado utilizar `if / else`.

---

## 2. `if / else`

O `if / else` oferece **dois caminhos possíveis**:

- Se a condição for verdadeira, executa o bloco do `if`;
- Se a condição for falsa, executa o bloco do `else`.

### Sintaxe

```python
if condição:
    # Código executado se a condição for True
else:
    # Código executado se a condição for False
```

### Exemplo

```python
saldo = 2000.0
saque = float(input("Informe o valor do saque: "))

if saldo >= saque:
    print("Realizando saque!")
else:
    print("Saldo insuficiente!")
```

> O `else` é opcional e só pode existir um `else` em cada estrutura condicional.

---

## 3. `if / elif / else`

Essa estrutura é usada quando existem **três ou mais possibilidades**.

- `if` testa a primeira condição;
- `elif` testa condições alternativas;
- `else` executa quando nenhuma condição anterior for verdadeira.

### Sintaxe

```python
if condição_1:
    # Código executado se condição_1 for True
elif condição_2:
    # Código executado se condição_1 for False
    # e condição_2 for True
else:
    # Código executado se todas as condições forem False
```

### Exemplo

```python
opcao = int(input(
    "Informe uma opção:\n"
    "[1] Sacar\n"
    "[2] Extrato\n"
))

if opcao == 1:
    valor = float(input("Informe a quantia para o saque: "))
    print(f"Solicitação de saque no valor de R$ {valor:.2f}")
elif opcao == 2:
    print("Exibindo o extrato...")
else:
    print("Opção inválida.")
```

### Observações

- É possível utilizar vários `elif`;
- Apenas o primeiro bloco cuja condição for verdadeira será executado;
- O `else` é opcional;
- O `else`, quando utilizado, deve ser o último bloco.

### Exemplo de fluxo

```python
nota = 8

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Aprovado")
else:
    print("Reprovado")
```

Mesmo que mais de uma condição pudesse ser considerada, apenas o primeiro bloco verdadeiro é executado.

---

## 4. `if` aninhado

Um `if` aninhado é uma estrutura condicional dentro de outra estrutura condicional.

Ele é útil quando uma condição depende de outra.

### Exemplo

```python
conta_normal = True
conta_universitaria = False
saldo = 500
saque = 700
cheque_especial = 300

if conta_normal:
    if saldo >= saque:
        print("Saque realizado com sucesso!")
    elif saque <= saldo + cheque_especial:
        print("Saque realizado com uso do cheque especial!")
    else:
        print("Saldo insuficiente!")
elif conta_universitaria:
    if saldo >= saque:
        print("Saque realizado com sucesso!")
    else:
        print("Saldo insuficiente!")
else:
    print("Tipo de conta inválido!")
```

### Atenção

Embora o `if` aninhado seja útil, muitos níveis de aninhamento podem dificultar a leitura. Quando possível:

- Use `elif`;
- Combine condições com `and` e `or`;
- Divida a lógica em funções;
- Evite blocos muito profundos.

---

## 5. `if` ternário

O `if` ternário permite escrever uma estrutura simples de `if / else` em uma única linha.

### Sintaxe

```python
valor_se_verdadeiro if condição else valor_se_falso
```

A ordem de leitura é:

1. Valor retornado se a condição for verdadeira;
2. Condição que será avaliada;
3. Valor retornado se a condição for falsa.

### Exemplo

```python
saldo = 2000
saque = 2500

status = "Sucesso" if saldo >= saque else "Falha"

print(f"{status} ao realizar o saque!")
```

Saída:

```text
Falha ao realizar o saque!
```

### Equivalência com `if / else`

A versão ternária:

```python
status = "Sucesso" if saldo >= saque else "Falha"
```

Equivale a:

```python
if saldo >= saque:
    status = "Sucesso"
else:
    status = "Falha"
```

### Quando utilizar

Use o `if` ternário quando a lógica for simples e fácil de entender.

Evite utilizá-lo quando:

- A condição for muito longa;
- Houver várias condições;
- O resultado ficar difícil de ler;
- For necessário executar várias instruções em cada alternativa.

---

## 6. `if` dentro de estruturas de repetição

O `if` pode ser utilizado dentro de loops, como `for` e `while`, para tomar decisões durante cada repetição.

### `break`

O `break` interrompe completamente o loop.

```python
for numero in range(5):
    if numero == 3:
        break

    print(numero)
```

Saída:

```text
0
1
2
```

Quando `numero` é igual a `3`, o loop é encerrado.

---

### `continue`

O `continue` interrompe apenas a iteração atual e passa para a próxima repetição.

```python
for numero in range(5):
    if numero == 2:
        continue

    print(numero)
```

Saída:

```text
0
1
3
4
```

Quando `numero` é igual a `2`, o `print()` é ignorado naquela iteração.

> `break` e `continue` não são estruturas condicionais. Eles são comandos de controle de loops que normalmente são utilizados dentro de um `if`.

---

## 7. Palavras-chave

|Palavra-chave|Significado|Função|
|---|---|---|
|`if`|Se|Testa uma condição|
|`elif`|Senão, se|Testa uma condição alternativa|
|`else`|Caso contrário|Executa quando as condições anteriores são falsas|
|`break`|Interromper|Encerra um loop|
|`continue`|Continuar|Pula para a próxima iteração do loop|

---

## 8. Comparações e valores booleanos

As condições normalmente utilizam operadores de comparação:

|Operador|Significado|
|---|---|
|`==`|Igual a|
|`!=`|Diferente de|
|`>`|Maior que|
|`>=`|Maior ou igual a|
|`<`|Menor que|
|`<=`|Menor ou igual a|

Exemplo:

```python
idade = 18

if idade >= 18:
    print("Maior de idade.")
```

Também é possível combinar condições usando operadores lógicos:

- `and`: todas as condições devem ser verdadeiras;
- `or`: pelo menos uma condição deve ser verdadeira;
- `not`: inverte o resultado.

```python
idade = 20
possui_documento = True

if idade >= 18 and possui_documento:
    print("Entrada permitida.")
```

## 9. Erros comuns

### Esquecer os dois-pontos

Incorreto:

```python
if saldo >= saque
    print("Saque permitido")
```

Correto:

```python
if saldo >= saque:
    print("Saque permitido")
```

---

### Utilizar indentação incorreta

Incorreto:

```python
if saldo >= saque:
print("Saque permitido")
```

Correto:

```python
if saldo >= saque:
    print("Saque permitido")
```

O código dentro do bloco deve ser indentado. Por convenção, utiliza-se **quatro espaços**.

---

### Confundir `=` com `==`

Incorreto:

```python
if idade = 18:
    print("Idade igual a 18")
```

Correto:

```python
if idade == 18:
    print("Idade igual a 18")
```

- `=` realiza uma atribuição;
- `==` compara dois valores.

---

### Utilizar vários `if` quando deveria usar `if / else`

Menos adequado:

```python
if saldo >= saque:
    print("Saque permitido")

if saldo < saque:
    print("Saldo insuficiente")
```

Mais adequado:

```python
if saldo >= saque:
    print("Saque permitido")
else:
    print("Saldo insuficiente")
```

---

## 10. Boas práticas

- Use nomes de variáveis claros;
- Mantenha as condições simples e legíveis;
- Utilize parênteses quando ajudarem a esclarecer a lógica;
- Evite muitos níveis de `if` aninhados;
- Prefira `if / elif / else` quando as alternativas forem mutuamente exclusivas;
- Use o `if` ternário apenas para condições simples;
- Mantenha a indentação consistente;
- Use `break` e `continue` com moderação;
- Evite condições muito longas; divida a lógica em variáveis ou funções quando necessário.

---

## Resumo final

|Estrutura|Uso|
|---|---|
|`if`|Executa um bloco se uma condição for verdadeira|
|`if / else`|Escolhe entre duas alternativas|
|`if / elif / else`|Escolhe entre várias alternativas|
|`if` aninhado|Coloca uma condição dentro de outra|
|`if` ternário|Representa um `if / else` simples em uma linha|
|`break`|Interrompe um loop|
|`continue`|Pula a iteração atual de um loop|
