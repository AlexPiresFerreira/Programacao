## Resumo rápido

- `input()` lê dados digitados pelo usuário.
- `print()` exibe dados na tela.

## Função `input()`

- Usada para receber dados da entrada padrão, geralmente o teclado
- Sempre retorna uma **string**

```python
nome = input("Informe o seu nome: ")
```

## Observação importante sobre `input()`

- Mesmo que o usuário digite um número, o valor recebido será uma string
- Se precisar usar como número, é necessário converter

```python
idade = int(input("Informe sua idade: "))
```

## Função `print()`

- Usada para exibir dados na saída padrão, geralmente a tela
- Converte os objetos para string antes de mostrar


```python
nome = "Guilherme"
sobrenome = "Carvalho"

print(nome, sobrenome)
```

## Parâmetros úteis de `print()`

### `sep`

- Define o separador entre os valores

```python
print(nome, sobrenome, sep="#")
```

### `end`

- Define o que aparece no final da saída

```python
print(nome, sobrenome, end="...\n")
```

### `file`

- Permite redirecionar a saída para outro destino

### `flush`

- Controla o envio imediato da saída para o terminal

## Exemplo completo

```python
nome = "Guilherme"
sobrenome = "Carvalho"

print(nome, sobrenome)
print(nome, sobrenome, end="...\n")
print(nome, sobrenome, sep="#")
```
