# Funções em Python

## Visão geral

Funções são blocos de código reutilizáveis que executam uma tarefa específica.

Elas ajudam a:

- Evitar repetição de código;
- Organizar melhor o programa;
- Dividir problemas maiores em partes menores;
- Melhorar a legibilidade e a manutenção;
- Facilitar testes e reaproveitamento de lógica.

Uma função pode:

- Receber dados por meio de parâmetros;
- Executar instruções;
- Retornar um resultado;
- Ser atribuída a uma variável;
- Ser passada como argumento para outra função;
- Ser retornada por outra função.

> Funções são uma das principais ferramentas da programação estruturada, mas também são utilizadas em outros paradigmas, como programação funcional e orientação a objetos.

---

## 1. Definindo uma função

Uma função é definida utilizando a palavra-chave `def`.

### Sintaxe

```python
def nome_da_funcao(parametros):
    # Corpo da função
    instruções
    return resultado
```

### Elementos principais

| Elemento         | Função                                     |
| ---------------- | ------------------------------------------ |
| `def`            | Inicia a definição da função               |
| `nome_da_funcao` | Nome utilizado para chamar a função        |
| `parametros`     | Dados que a função pode receber            |
| `:`              | Inicia o bloco da função                   |
| Indentação       | Define quais instruções pertencem à função |
| `return`         | Encerra a função e devolve um valor        |

### Exemplo básico

```python
def exibir_mensagem():
    print("Olá, mundo!")

exibir_mensagem()
```

A função só é executada quando é chamada:

```python
exibir_mensagem()
```

## 2. Parâmetros e argumentos

Embora sejam frequentemente usados como sinônimos, existe uma diferença:

- **Parâmetro:** variável declarada na definição da função;
- **Argumento:** valor enviado quando a função é chamada.

```python
def saudar(nome):  # nome é um parâmetro
    print(f"Olá, {nome}!")

saudar("Alex")      # "Alex" é um argumento
```

Uma função pode receber vários parâmetros:

```python
def apresentar(nome, idade):
    print(f"Nome: {nome}")
    print(f"Idade: {idade}")

apresentar("Alex", 25)
```

## 3. Chamando funções

Uma função é chamada utilizando seu nome seguido de parênteses:

```python
nome_da_funcao()
```

Se a função possuir parâmetros, os argumentos são colocados dentro dos parênteses:

```python
def somar(a, b):
    return a + b

resultado = somar(2, 3)

print(resultado)
# 5
```

## 4. `return`

A palavra-chave `return`:

- Encerra a execução da função;
- Devolve um valor para quem chamou a função;
- Permite armazenar o resultado em uma variável;
- Pode retornar qualquer objeto válido em Python.

```python
def dobro(numero):
    return numero * 2

resultado = dobro(5)

print(resultado)
# 10
```

### `return` encerra a função

```python
def verificar_idade(idade):
    if idade >= 18:
        return "Maior de idade"

    return "Menor de idade"

print(verificar_idade(20))
# Maior de idade
```

Quando o primeiro `return` é executado, a função termina imediatamente.

### Função sem `return`

Se uma função não possuir um `return` explícito, ela retorna `None`:

```python
def exibir_mensagem():
    print("Olá!")

resultado = exibir_mensagem()

print(resultado)
# None
```

O mesmo acontece quando utilizamos `return` sem um valor:

```python
def sem_retorno():
    return

print(sem_retorno())
# None
```

## 5. Retornando vários valores

Em Python, é possível retornar vários valores separados por vírgula.

Na prática, esses valores são agrupados em uma tupla:

```python
def obter_antecessor_e_sucessor(numero):
    antecessor = numero - 1
    sucessor = numero + 1

    return antecessor, sucessor

resultado = obter_antecessor_e_sucessor(10)

print(resultado)
# (9, 11)
```

Também é possível desempacotar os valores diretamente:

```python
antecessor, sucessor = obter_antecessor_e_sucessor(10)

print(antecessor)  # 9
print(sucessor)    # 11
```

### Outro exemplo

```python
def calcular_estatisticas(numeros):
    return min(numeros), max(numeros), sum(numeros)

menor, maior, total = calcular_estatisticas([10, 20, 30])

print(menor)  # 10
print(maior)  # 30
print(total)  # 60
```

## 6. Parâmetros posicionais

Argumentos posicionais são associados aos parâmetros com base na ordem em que são enviados.

```python
def apresentar(nome, idade):
    print(f"{nome} tem {idade} anos.")

apresentar("Alex", 25)
```

Nesse exemplo:

- `"Alex"` é atribuído a `nome`;
- `25` é atribuído a `idade`.

A ordem precisa ser respeitada:

```python
apresentar(25, "Alex")
```

Esse código não gera necessariamente um erro de sintaxe, mas os valores serão associados aos parâmetros incorretamente.

## 7. Argumentos nomeados

Argumentos nomeados são enviados no formato:

```python
parametro=valor
```


```python
def salvar_carro(marca, modelo, ano, placa):
    print(f"Carro cadastrado: {marca}/{modelo}/{ano}/{placa}")

salvar_carro(
    marca="Fiat",
    modelo="Palio",
    ano=1999,
    placa="ABC-1234"
)
```

A principal vantagem é deixar a chamada mais clara e permitir alterar a ordem dos argumentos:

```python
salvar_carro(
    placa="ABC-1234",
    ano=1999,
    modelo="Palio",
    marca="Fiat"
)
```

Também é possível misturar argumentos posicionais e nomeados, mas os posicionais devem vir primeiro:

```python
salvar_carro(
    "Fiat",
    modelo="Palio",
    ano=1999,
    placa="ABC-1234"
)
```

## 8. Desempacotamento com `*` e `**`

### Desempacotando uma lista ou tupla com `*`

```python
def somar(a, b, c):
    return a + b + c

valores = [10, 20, 30]

resultado = somar(*valores)

print(resultado)
# 60
```

O `*` envia cada item da lista como um argumento separado.

### Desempacotando um dicionário com `**`

```python
def salvar_carro(marca, modelo, ano, placa):
    print(f"{marca}/{modelo}/{ano}/{placa}")

dados = {
    "marca": "Fiat",
    "modelo": "Palio",
    "ano": 1999,
    "placa": "ABC-1234"
}

salvar_carro(**dados)
```

As chaves do dicionário precisam corresponder aos nomes dos parâmetros.

## 9. Parâmetros com valores padrão

Um parâmetro pode possuir um valor padrão. Nesse caso, o argumento se torna opcional.

```python
def saudar(nome="Anônimo"):
    print(f"Seja bem-vindo, {nome}!")

saudar()
# Seja bem-vindo, Anônimo!

saudar("Alex")
# Seja bem-vindo, Alex!
```

### Exemplo com vários parâmetros

```python
def somar(numero_1, numero_2=10):
    return numero_1 + numero_2

print(somar(5))
# 15

print(somar(5, 20))
# 25
```

> Parâmetros obrigatórios devem aparecer antes dos parâmetros com valor padrão.

Correto:

```python
def exemplo(nome, idade=18):
    pass
```

Incorreto:

```python
def exemplo(nome="Anônimo", idade):
    pass
```

## 10. `*args`

O parâmetro `*args` permite receber vários argumentos posicionais.

Dentro da função, os argumentos são armazenados em uma tupla.

```python
def somar(*valores):
    return sum(valores)

print(somar(1, 2))
# 3

print(somar(1, 2, 3, 4))
# 10
```

É possível combinar parâmetros normais com `*args`:

```python
def exibir_numeros(mensagem, *numeros):
    print(mensagem)

    for numero in numeros:
        print(numero)

exibir_numeros("Números informados:", 10, 20, 30)
```

> O nome `args` é uma convenção. O comportamento especial vem do asterisco `*`.

## 11. `**kwargs`

O parâmetro `**kwargs` permite receber vários argumentos nomeados.

Dentro da função, os argumentos são armazenados em um dicionário.

```python
def exibir_dados(**dados):
    for chave, valor in dados.items():
        print(f"{chave}: {valor}")

exibir_dados(
    nome="Alex",
    idade=25,
    cidade="São Paulo"
)
```

Saída:

```text
nome: Alex
idade: 25
cidade: São Paulo
```

Também é possível combinar parâmetros normais, `*args` e `**kwargs`:

```python
def exemplo(nome, *args, **kwargs):
    print(f"Nome: {nome}")
    print(f"Argumentos posicionais: {args}")
    print(f"Argumentos nomeados: {kwargs}")

exemplo(
    "Alex",
    10,
    20,
    cidade="São Paulo",
    ativo=True
)
```

### Ordem recomendada

```python
def funcao(parametros_normais, *args, parametros_nomeados, **kwargs):
    pass
```

criar_carro(

Nesse caso, `modelo`, `ano` e `placa` não podem ser enviados por nome.

## 15. Escopo de variáveis

Escopo define onde uma variável pode ser acessada.

### Variável local

Uma variável criada dentro de uma função é local e normalmente só pode ser utilizada dentro dela.

```python
def exemplo():
    mensagem = "Olá"
    print(mensagem)

exemplo()
```

A variável `mensagem` não existe fora da função:

```python
print(mensagem)  # NameError
```

### Variável global

Uma variável criada fora de uma função pertence ao escopo global:

```python
saldo = 1000

def exibir_saldo():
    print(saldo)

exibir_saldo()
# 1000
```

A função consegue consultar a variável global, mas isso não significa que seja uma boa prática modificá-la diretamente.

## 16. A palavra-chave `global`

A palavra-chave `global` permite modificar uma variável global dentro de uma função.

```python
saldo = 1000

def adicionar_bonus(valor):
    global saldo
    saldo += valor

adicionar_bonus(500)

print(saldo)
# 1500
```

### Por que evitar `global`?

O uso excessivo de variáveis globais pode:

- Dificultar o rastreamento das alterações;
- Criar dependências ocultas;
- Aumentar a chance de efeitos colaterais;
- Tornar os testes mais difíceis.

Prefira retornar o novo valor:

```python
def adicionar_bonus(saldo, valor):
    return saldo + valor

saldo = 1000
saldo = adicionar_bonus(saldo, 500)

print(saldo)
# 1500
```

## 17. Funções como objetos de primeira classe

Em Python, funções são objetos de primeira classe. Isso significa que podem ser:

- Atribuídas a variáveis;
- Passadas como argumentos;
- Armazenadas em listas, tuplas ou dicionários;
- Retornadas por outras funções.

### Atribuindo uma função a uma variável

```python
def somar(a, b):
    return a + b

operacao = somar

print(operacao(2, 3))
# 5
```

### Passando uma função como argumento

```python
def somar(a, b):
    return a + b

def executar_operacao(a, b, operacao):
    return operacao(a, b)

resultado = executar_operacao(10, 5, somar)

print(resultado)
# 15
```

### Armazenando funções em uma lista

```python
def somar(a, b):
    return a + b

def multiplicar(a, b):
    return a * b

operacoes = [somar, multiplicar]

print(operacoes[0](2, 3))
# 5

print(operacoes[1](2, 3))
# 6
```

## 18. Funções aninhadas e closures

Uma função pode ser definida dentro de outra função.

```python
def criar_saudacao(saudacao):
    def saudar(nome):
        return f"{saudacao}, {nome}!"

    return saudar

saudar_bom_dia = criar_saudacao("Bom dia")

print(saudar_bom_dia("Alex"))
# Bom dia, Alex!
```

Nesse exemplo:

- `criar_saudacao()` cria uma função;
- A função interna `saudar()` utiliza a variável `saudacao`;
- A função interna é retornada;
- A função retornada mantém acesso ao valor de `saudacao`.

Esse comportamento é conhecido como **closure**.

## 19. Funções anônimas com `lambda`

Uma expressão `lambda` cria uma função pequena e sem nome.

### Sintaxe

```python
lambda parametros: expressão
```

### Exemplo

```python
dobro = lambda numero: numero * 2

print(dobro(5))
# 10
```

Uma função `lambda` equivale, nesse caso, a:

```python
def dobro(numero):
    return numero * 2
```

### Uso com `sorted()`

```python
nomes = ["Ana", "Alex", "Beatriz", "Caio"]

ordenados = sorted(nomes, key=lambda nome: len(nome))

print(ordenados)
```

> Use `lambda` apenas para expressões simples. Para lógica mais complexa, prefira uma função definida com `def`.

## 20. `yield` e funções geradoras

A palavra-chave `yield` transforma uma função em uma **função geradora**.

Ao contrário de `return`, `yield`:

- Produz um valor por vez;
- Pausa a execução da função;
- Mantém o estado da função;
- Permite continuar a execução posteriormente;
- É útil para trabalhar com sequências grandes sem criar todos os valores de uma vez.

```python
def contar():
    yield 1
    yield 2
    yield 3

gerador = contar()

print(next(gerador))  # 1
print(next(gerador))  # 2
print(next(gerador))  # 3
```

Também é possível percorrer o gerador com `for`:

```python
def contar():
    yield 1
    yield 2
    yield 3

for numero in contar():
    print(numero)
```

### Gerador com `range`

```python
def contar_ate(limite):
    numero = 1

    while numero <= limite:
        yield numero
        numero += 1

for numero in contar_ate(3):
    print(numero)
```

## 21. Anotações de tipo

Anotações de tipo permitem documentar os tipos esperados para parâmetros e valores de retorno.

```python
def saudar(nome: str) -> str:
    return f"Olá, {nome}!"
```

Nesse exemplo:

- `nome: str` indica que `nome` deve ser uma string;
- `-> str` indica que a função deve retornar uma string.

As anotações são opcionais e, sozinhas, não impedem que outros tipos sejam enviados em tempo de execução. Elas são utilizadas principalmente por ferramentas de análise estática, IDEs, documentação e verificadores de tipo.  

PEP 3107 – Function Annotations | peps.python.org + 1

### Exemplos

```python
def somar(a: int, b: int) -> int:
    return a + b
```

```python
def calcular_media(numeros: list[float]) -> float:
    return sum(numeros) / len(numeros)
```

```python
def exibir_mensagem() -> None:
    print("Olá!")
```

### Acessando as anotações

As anotações ficam disponíveis no atributo `__annotations__`:

```python
def somar(a: int, b: int) -> int:
    return a + b

print(somar.__annotations__)
```

Saída semelhante a:

```python
{'a': <class 'int'>, 'b': <class 'int'>, 'return': <class 'int'>}
```

> A PEP 3107 define a sintaxe geral das anotações de função, enquanto a PEP 484 estabelece convenções para seu uso como dicas de tipo.  
> 
> PEP 3107 – Function Annotations | peps.python.org + 1

## 22. Docstrings

Docstrings são textos utilizados para documentar funções, classes e módulos.

```python
def calcular_area_retangulo(base: float, altura: float) -> float:
    """Retorna a área de um retângulo."""
    return base * altura
```

A documentação pode ser acessada com `.__doc__`:

```python
print(calcular_area_retangulo.__doc__)
```

Também é possível usar `help()`:

```python
help(calcular_area_retangulo)
```

### Docstring detalhada

```python
def calcular_area_retangulo(base: float, altura: float) -> float:
    """
    Calcula a área de um retângulo.

    Args:
        base: Medida da base do retângulo.
        altura: Medida da altura do retângulo.

    Returns:
        A área do retângulo.
    """
    return base * altura
```

## 24. Erros comuns

### Esquecer os parênteses ao chamar uma função

```python
def exibir_mensagem():
    print("Olá!")

exibir_mensagem
```

Nesse caso, a função não é executada. O código apenas referencia o objeto função.

Correto:

```python
exibir_mensagem()
```

---

### Esquecer o `return`

```python
def somar(a, b):
    a + b

resultado = somar(2, 3)

print(resultado)
# None
```

Correto:

```python
def somar(a, b):
    return a + b
```

---

### Usar parâmetros obrigatórios depois de parâmetros padrão

Incorreto:

```python
def exemplo(nome="Anônimo", idade):
    pass
```

Correto:

```python
def exemplo(nome, idade=18):
    pass
```

---

### Usar `global` sem necessidade

Evite:

```python
saldo = 100

def adicionar(valor):
    global saldo
    saldo += valor
```

Prefira:

```python
def adicionar(saldo, valor):
    return saldo + valor

saldo = adicionar(100, 50)
```

---

### Utilizar lista como valor padrão

Evite este padrão:

```python
def adicionar_item(item, lista=[]):
    lista.append(item)
    return lista
```

A mesma lista pode ser reutilizada entre chamadas.

Prefira:

```python
def adicionar_item(item, lista=None):
    if lista is None:
        lista = []

    lista.append(item)
    return lista
```

---

### Confundir `return` com `print`

`print()` exibe um valor, enquanto `return` devolve um valor para quem chamou a função.

```python
def com_print():
    print(10)

def com_return():
    return 10

resultado_1 = com_print()
resultado_2 = com_return()

print(resultado_1)  # None
print(resultado_2)  # 10
```

## 25. Boas práticas

- Defina funções com uma responsabilidade clara;
- Use nomes descritivos em `snake_case`;
- Prefira funções pequenas e fáceis de testar;
- Evite modificar variáveis globais;
- Prefira retornar valores em vez de produzir efeitos colaterais;
- Use valores padrão quando fizer sentido;
- Documente funções públicas com docstrings;
- Utilize anotações de tipo para melhorar a documentação e a análise do código;
- Use `*args` e `**kwargs` somente quando forem realmente necessários;
- Evite funções com muitos parâmetros;
- Mantenha a ordem dos parâmetros consistente;
- Use `lambda` apenas para operações simples;
- Prefira `yield` quando precisar produzir valores sob demanda;
- Não use nomes de funções que conflitem com funções built-in, como `list`, `str`, `sum` ou `type`.

## Exemplo completo

```python
def calcular_total(
    valores: list[float],
    desconto: float = 0,
    /,
    *,
    moeda: str = "R$"
) -> str:
    """
    Calcula o total de uma lista de valores com desconto.

    Args:
        valores: Lista de valores.
        desconto: Percentual de desconto.
        moeda: Símbolo da moeda.

    Returns:
        Total formatado como texto.
    """
    subtotal = sum(valores)
    total = subtotal - (subtotal * desconto / 100)

    return f"{moeda} {total:.2f}"


valores = [100.0, 50.0, 25.0]

resultado = calcular_total(
    valores,
    10,
    moeda="R$"
)

print(resultado)
# R$ 157.50
```

Neste exemplo foram utilizados:

- Função com `def`;
- Parâmetro posicional;
- Parâmetros com valores padrão;
- Parâmetros somente nomeados;
- Anotações de tipo;
- Docstring;
- `return`;
- Função built-in `sum()`;
- Formatação de strings.
