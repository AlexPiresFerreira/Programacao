
### Abrir arquivo com `with`

```python
with open("arquivo.txt", mode="r", encoding="utf-8") as arquivo:
    conteudo = arquivo.read()
```

### Modos mais usados

- `"r"` → leitura
- `"w"` → escrita
- `"a"` → append

### Vantagem do `with`

- Abre e fecha o arquivo automaticamente.

### Ler linha por linha

```python
with open("hosts.txt", mode="r", encoding="utf-8") as arquivo:
    for numero_linha, linha in enumerate(arquivo, start=1):
        print(f"Linha {numero_linha}: {linha.strip()}")
```

### Erros comuns

- `FileNotFoundError` → arquivo não existe
- `PermissionError` → sem permissão de acesso
- `Exception` → qualquer outro erro
