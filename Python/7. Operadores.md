
# Operadores em Python

## Visão geral

Operadores são símbolos ou palavras-chave usados para realizar:

- Cálculos matemáticos;
- Comparações entre valores;
- Atribuições e atualizações de variáveis;
- Combinação de expressões booleanas;
- Verificação da identidade de objetos;
- Verificação de pertencimento a sequências.

---

## 1. Operadores aritméticos

São usados para realizar operações matemáticas.

|Operador|Operação|Exemplo|Resultado|
|---|---|---|---|
|`+`|Adição|`10 + 3`|`13`|
|`-`|Subtração|`10 - 3`|`7`|
|`*`|Multiplicação|`10 * 3`|`30`|
|`/`|Divisão|`10 / 3`|`3.333...`|
|`//`|Divisão inteira|`10 // 3`|`3`|
|`%`|Módulo, ou resto da divisão|`10 % 3`|`1`|
|`**`|Exponenciação|`2 ** 10`|`1024`|

### Exemplos

```python
print(1 + 1)    # 2
print(10 - 2)   # 8
print(4 * 3)    # 12
print(12 / 3)   # 4.0
print(12 // 2)  # 6
print(10 % 3)   # 1
print(2 ** 3)   # 8
```

### Observações

- O operador `/` sempre retorna um número do tipo `float`.
- O operador `//` realiza a divisão com arredondamento para baixo, também chamado de _floor division_.
- O operador `%` retorna o resto da divisão.
- O operador `**` pode ser usado para calcular potências.

```python
print(10 / 3)    # 3.3333333333333335
print(10 // 3)   # 3
print(10 % 3)    # 1
print(2 ** 10)   # 1024
```

---

## 2. Precedência dos operadores

A precedência define a ordem em que o Python executa as operações.

1. Parênteses: `()`;
2. Exponenciação: `**`;
3. Sinais unários: `+x`, `-x`;
4. Multiplicação, divisão, divisão inteira e módulo: `*`, `/`, `//`, `%`;
5. Adição e subtração: `+`, `-`;
6. Operadores de comparação: `<`, `<=`, `>`, `>=`, `==`, `!=`;
7. Operador lógico `not`;
8. Operador lógico `and`;
9. Operador lógico `or`.

> Em expressões complexas, use parênteses para deixar a intenção clara, mesmo quando eles não forem obrigatórios.

### Exemplos

```python
print(10 - 5 * 2)       # 0
print((10 - 5) * 2)     # 10
print(10 ** 2 * 2)      # 200
print(10 ** (2 * 2))    # 10000
print(10 / 2 * 4)       # 20.0
print(2 + 3 * 4)        # 14
print((2 + 3) * 4)      # 20
print(2 ** 3 + 1)       # 9
print(10 - 4 // 2)      # 8
```

## 3. Operadores de comparação

São usados para comparar valores. O resultado de uma comparação é sempre um valor booleano:

- `True`: verdadeiro;
- `False`: falso.

|Operador|Significado|
|---|---|
|`==`|Igual a|
|`!=`|Diferente de|
|`>`|Maior que|
|`>=`|Maior ou igual a|
|`<`|Menor que|
|`<=`|Menor ou igual a|
### Exemplos


```python
print(5 == 5)   # True
print(5 != 3)   # True
print(5 > 3)    # True
print(5 >= 5)   # True
print(3 < 5)    # True
print(3 <= 3)   # True

saldo = 450
saque = 200

print(saldo == saque)  # False
print(saldo != saque)  # True
print(saldo > saque)   # True
print(saldo >= saque)  # True
print(saldo < saque)   # False
print(saldo <= saque)  # False

```

> **Atenção:** `=` é usado para atribuição, enquanto `==` é usado para comparação.

## 4. Operadores de atribuição

São usados para atribuir ou atualizar o valor de uma variável.

|Operador|Equivalente a|
|---|---|
|`=`|Atribuição simples|
|`+=`|`x = x + valor`|
|`-=`|`x = x - valor`|
|`*=`|`x = x * valor`|
|`/=`|`x = x / valor`|
|`//=`|`x = x // valor`|
|`%=`|`x = x % valor`|
|`**=`|`x = x ** valor`|
### Exemplos

```python
saldo = 500

saldo += 200   # saldo = 700
saldo -= 100   # saldo = 600
saldo *= 2     # saldo = 1200
saldo /= 5     # saldo = 240.0
saldo //= 5    # saldo = 48.0
saldo %= 40    # saldo = 8.0
saldo **= 2    # saldo = 64.0

print(saldo)   # 64.0
```

### Observação

A atribuição combinada:


```python
saldo += 200
```

é uma forma abreviada de escrever:

```python
saldo = saldo + 200
```

O mesmo princípio vale para os demais operadores de atribuição.

## 5. Operadores lógicos

São usados para combinar ou inverter expressões booleanas.

|Operador|Significado|
|---|---|
|`and`|Retorna `True` quando todas as condições são verdadeiras|
|`or`|Retorna `True` quando pelo menos uma condição é verdadeira|
|`not`|Inverte o resultado booleano|
### Exemplos básicos

```python
print(True and False)  # False
print(True or False)   # True
print(not True)        # False
```

### Exemplos com comparações

```python
x = 5

print(x > 3 and x < 10)  # True
print(x < 3 or x < 10)   # True
print(not x > 3)         # False

saldo = 1000
saque = 200
limite = 100

print(saldo >= saque and saque <= limite)  # False
print(saldo >= saque or saque <= limite)   # True
print(not saldo > 1500)                    # True

```

### Uso de parênteses

Parênteses ajudam a organizar expressões lógicas e controlar a ordem de avaliação.

```python
saldo = 1000
saque = 250
limite = 200
conta_especial = True

resultado = (
    (saldo >= saque and saque <= limite)
    or
    (conta_especial and saldo >= saque)
)

print(resultado)  # True
```

Nesse exemplo, a segunda parte da expressão é verdadeira porque `conta_especial` é `True` e o saldo é suficiente.

## 6. Operadores de identidade

São usados para verificar se duas variáveis se referem ao **mesmo objeto** na memória.

| Operador | Significado          |
| -------- | -------------------- |
| `is`     | É o mesmo objeto     |
| `is not` | Não é o mesmo objeto |

### Exemplo

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)   # True
print(a is c)   # False
print(a == c)   # True
```

### Entendendo o exemplo

- `a` e `b` apontam para a mesma lista;
- `a` e `c` são listas diferentes;
- Mesmo sendo objetos diferentes, `a` e `c` possuem os mesmos valores.

Por isso:

```python
a is b   # True: mesmo objeto
a is c   # False: objetos diferentes
a == c   # True: valores iguais
```

> **Regra importante:**

> - Use `is` e `is not` para comparar identidade;
> - Use `==` e `!=` para comparar.

### Uso comum com `None`

O uso mais comum de `is` é verificar se uma variável possui o valor especial `None`:

```python
resultado = None

if resultado is None:
    print("Nenhum resultado foi encontrado")
```

> Evite usar `is` para comparar números, strings ou outros valores diretamente. Embora alguns casos possam retornar resultados inesperados ou parecer funcionar, o operador correto para comparar valores é `==`.

## 7. Operadores de associação

São usados para verificar se um elemento pertence a uma sequência ou coleção.

|Operador|Significado|
|---|---|
|`in`|Pertence à sequência ou coleção|
|`not in`|Não pertence à sequência ou coleção|

### Exemplos com listas


```python
numeros = [1, 2, 3, 4, 5]

print(3 in numeros)       # True
print(6 not in numeros)   # True
```

### Exemplos com strings

```python
curso = "Python"

print("P" in curso)       # True
print("x" not in curso)   # True
```

Também é possível verificar se uma palavra ou trecho está contido em uma string:

```python
curso = "Curso de Python"

print("Python" in curso)  # True
print("Java" not in curso)  # True
```

### Outros exemplos

```python
frutas = ["laranja", "uva", "limão"]
saques = [1500, 100]

print("maçã" not in frutas)  # True
print(200 in saques)         # False
```

## Diferenças importantes

### `=` x `==`


```python
nome = "Alex"       # Atribuição
print(nome == "Alex")  # Comparação: True
```

- `=` atribui um valor;
- `==` verifica se dois valores são iguais.

### `==` x `is`

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True: os valores são iguais
print(a is b)  # False: são objetos diferentes
```

- `==` compara valores;
- `is` compara identidade, ou seja, se é o mesmo objeto na memória.

### `in` x `not in`


```python
linguagens = ["Python", "Java", "C"]

print("Python" in linguagens)      # True
print("JavaScript" not in linguagens)  # True
```

- `in` verifica se um elemento pertence a uma coleção;
- `not in` verifica se um elemento não pertence a uma coleção.
