
## Resumo rápido

- Variáveis armazenam valores que podem mudar durante a execução do programa.
- Constantes armazenam valores que não devem ser alterados.

## Variáveis

- Em Python, não é necessário declarar o tipo manualmente
- O tipo é definido automaticamente pelo valor atribuído

python

```python
age = 23
name = "Guilherme"

print(f"Meu nome é {name} e eu tenho {age} ano(s) de idade.")
```

## Alterando valores

- Para mudar o valor de uma variável, basta atribuir outro valor

```python
age = 28
name = "Guilherme"

print(f"Meu nome é {name} e eu tenho {age} ano(s) de idade.")

age = 27
name = "Giovanna"

print(f"Meu nome é {name} e eu tenho {age} ano(s) de idade.")
```

## Concatenação e interpolação

- Em Python, o jeito mais legível de unir texto e variáveis é usar **f-strings**

```python
variavel = "Python"
texto = f"Aprendendo {variavel} com {variavel}"
print(texto)
```

## Constantes

- Constantes são valores que devem permanecer fixos durante a execução
- Python não possui uma palavra reservada específica para constante
- Por convenção, usa-se **nome em maiúsculas**

```python
ABS_PATH = "/home/guilherme/Documents/python_course/"
DEBUG = True
STATES = ["SP", "RJ", "MG"]
AMOUNT = 30.2
```

## Boas práticas

- Use `snake_case` para variáveis
- Prefira nomes sugestivos
- Use maiúsculas para constantes por convenção
## 2. Variáveis especiais

### `__name__`

- Se o arquivo for executado diretamente:
    - `__name__ == "__main__"`
- Se o arquivo for importado em outro:
    - `__name__` recebe o nome do módulo

### Teste principal

```python
if __name__ == "__main__":
    print("Executando diretamente")
```

- Serve para verificar se o script está sendo executado nele mesmo.
