
## Visão geral

A manipulação de arquivos permite **armazenar, ler, alterar e organizar dados** fora da memória temporária do programa.

Os arquivos são importantes porque permitem:

- Persistir informações após o encerramento do programa;
- Armazenar configurações;
- Registrar logs;
- Salvar relatórios;
- Ler dados externos;
- Compartilhar informações entre aplicações.

Python permite trabalhar com:

- Arquivos de texto, como `.txt`;
- Arquivos CSV;
- Arquivos binários;
- Arquivos e diretórios do sistema.

---

# 4. Modos de abertura

O segundo argumento de `open()` define a operação que será realizada.

|Modo|Função|
|---|---|
|`r`|Leitura|
|`w`|Escrita, substituindo o conteúdo|
|`a`|Adição ao final do arquivo|
|`x`|Criação exclusiva de um novo arquivo|
|`b`|Modo binário|
|`t`|Modo texto, padrão|

```python
arquivo = open("teste.txt", "r", encoding="utf-8")

conteudo = arquivo.read()

```

O fechamento é importante para:

- Liberar recursos do sistema;
- Garantir que os dados sejam gravados;
- Evitar corrupção de arquivos;
- Liberar o arquivo para outras operações.

Entretanto, fechar manualmente pode ser esquecido quando ocorre uma exceção. Por isso, prefira o `with`.

# 18. Tratamento de exceções

Erros podem acontecer durante a manipulação de arquivos.

Exemplos:

- Arquivo inexistente;
- Falta de permissão;
- Caminho inválido;
- Codificação incorreta;
- Tentativa de abrir um diretório como arquivo;
- Falta de espaço em disco.

Utilize `try`, `except`, `else` e `finally` para tratar essas situações.

# 27. Boas práticas com CSV

- Utilize o módulo `csv`;
- Prefira `csv.reader` ou `csv.DictReader` para leitura;
- Prefira `csv.writer` ou `csv.DictWriter` para escrita;
- Informe `newline=""` ao abrir arquivos CSV;
- Informe `encoding="utf-8"`;
- Verifique o delimitador utilizado;
- Trate o cabeçalho corretamente;
- Converta strings para números quando necessário;
- Trate exceções de leitura e gravação;
- Evite dividir linhas manualmente com `.split(",")`, pois campos podem conter vírgulas entre aspas.

def criar_arquivo():
    if not ARQUIVO.exists():
        with ARQUIVO.open(
            "w",
            encoding="utf-8",
            newline=""
        ) as arquivo:
            escritor = csv.DictWriter(
                arquivo,
                fieldnames=CAMPOS
            )

            escritor.writeheader()


def adicionar_pessoa(nome, idade, cidade):
    with ARQUIVO.open(
        "a",
        encoding="utf-8",
        newline=""
    ) as arquivo:
        escritor = csv.DictWriter(
            arquivo,
            fieldnames=CAMPOS
        )

        escritor.writerow({
            "nome": nome,
            "idade": idade,
            "cidade": cidade
        })


def listar_pessoas():
    with ARQUIVO.open(
        "r",
        encoding="utf-8",
        newline=""
    ) as arquivo:
        leitor = csv.DictReader(arquivo)

        for pessoa in leitor:
            print(
                f"{pessoa['nome']} - "
                f"{pessoa['idade']} anos - "
                f"{pessoa['cidade']}"
            )


criar_arquivo()
adicionar_pessoa("Alex", 25, "São Paulo")
adicionar_pessoa("Maria", 30, "Rio de Janeiro")

listar_pessoas()

# 31. Checklist para trabalhar com arquivos

Antes de manipular um arquivo, verifique:

- [ ] O caminho está correto?
- [ ] O arquivo existe?
- [ ] Tenho permissão para acessá-lo?
- [ ] O modo de abertura é adequado?
- [ ] A codificação está correta?
- [ ] O arquivo será fechado automaticamente?
- [ ] O conteúdo anterior será preservado?
- [ ] Preciso tratar alguma exceção?
- [ ] O arquivo é grande o suficiente para exigir leitura linha a linha?
- [ ] É um arquivo de texto, binário ou CSV?

# Resumo final

- A função `open()` abre arquivos para leitura e escrita;
- O modo `r` é utilizado para leitura;
- O modo `w` substitui o conteúdo;
- O modo `a` adiciona conteúdo ao final;
- O modo `x` cria um arquivo novo;
- Os modos `rb` e `wb` trabalham com arquivos binários;
- `read()` lê todo o conteúdo;
- `readline()` lê uma linha;
- `readlines()` retorna todas as linhas em uma lista;
- `write()` escreve uma string;
- `writelines()` escreve várias strings;
- O bloco `with` fecha o arquivo automaticamente;
- `pathlib` facilita a manipulação de caminhos;
- `os` oferece funções relacionadas ao sistema operacional;
- `shutil` permite copiar, mover e remover arquivos e diretórios;
- `try/except` permite tratar erros;
- `encoding="utf-8"` ajuda a evitar problemas com caracteres especiais;
- Arquivos grandes devem ser processados linha a linha;
- O módulo `csv` deve ser utilizado para ler e escrever arquivos CSV;
- `newline=""` é recomendado ao trabalhar com CSV.
