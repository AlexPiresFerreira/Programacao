## 1. Conceitos Fundamentais

### O que é Data Science?

> Ciência que estuda as informações — seu processo de **captura, transformação, geração e análise**.

### ETL

|Etapa|Significado|O que faz|
|---|---|---|
|**E**|Extract|Extrai os dados da fonte|
|**T**|Transform|Limpa e prepara os dados|
|**L**|Load|Carrega para o destino final|

> Muito utilizado em **BI (Business Intelligence)**

### Tipos de Dados no Pandas

|Tipo|Descrição|Exemplo|
|---|---|---|
|`int64`|Número inteiro|42|
|`float64`|Número decimal|3.14|
|`object`|Texto / string|"Brasil"|
|`datetime64[ns]`|Data e hora|2019-01-01|
|`category`|Dado qualitativo|"TipoA", "TipoB"|
|`bool`|Booleano|True / False|

## 2. Estruturas de Dados Python

### 📋 Listas

```python
animais = ["cachorro", "gato", 12345, 6.5]

animais[0]          # Acessa o 1º elemento → "cachorro"
animais[0] = "papagaio"  # Substitui elemento
animais.remove("gato")   # Remove elemento
animais.append(["leão"]) # Adiciona ao final
animais.extend(["cobra"]) # Concatena lista
len(animais)        # Tamanho da lista
"gato" in animais   # Verifica existência → False
animais.count("leão")    # Conta ocorrências
lista.sort()        # Ordena a lista
max(lista) / min(lista)  # Maior / menor valor
```

### 📦 Tuplas

> Imutáveis — não podem ser alteradas após criação.

```python
tp = ("Banana", "Maçã", 10, 50)

tp[0]       # Acessa elemento → "Banana"
tp[0:2]     # Fatia → ("Banana", "Maçã")
tp.count("Maçã")  # Conta ocorrências

# ❌ tp[0] = "Laranja"  → ERRO! Tuplas são imutáveis
```

### 📖 Dicionários

> Estrutura de **chave → valor**.

```python
dc = {"Maçã": 20, "Banana": 10, "Laranja": 15}

dc["Maçã"]              # Acessa valor → 20
dc["Maçã"] = 25         # Atualiza valor
dc.keys()               # Retorna todas as chaves
dc.values()             # Retorna todos os valores
dc.setdefault("Limão", 22)  # Insere se não existir
```

### Series vs DataFrame

|Conceito|Descrição|Representa|
|---|---|---|
|**Series**|Array unidimensional com rótulos|Coluna / linha|
|**DataFrame**|Tabela com colunas e linhas rotuladas|Planilha completa|

```python

# Series categórica (qualitativa)

# DataFrame manual

})
```

## 6. Limpeza e Tratamento de Dados

### 🔍 Identificar valores faltantes (NaN)

```python
df.isnull().sum()           # Total de nulos por coluna
df.isna().sum()             # Equivalente ao isnull
```

### 🩹 Tratar valores faltantes

```python
# Substituir pela média
df["Vendas"].fillna(df["Vendas"].mean(), inplace=True)

# Substituir por zero
df["Vendas"].fillna(0, inplace=True)

# Substituir por valor fixo
df["coluna"].fillna("Desconhecido", inplace=True)

# Remover linhas com qualquer nulo
df.dropna(inplace=True)

# Remover nulos apenas de uma coluna específica
df.dropna(subset=["Vendas"], inplace=True)

# Remover linhas em que TODAS as colunas são nulas
df.dropna(how="all", inplace=True)
```

### 🔄 Alterar tipo de dado

```python
df["LojaID"] = df["LojaID"].astype("object")  # Para texto
df["Qtde"]   = df["Qtde"].astype("int64")     # Para inteiro
df["Vendas"] = df["Vendas"].astype("float64") # Para decimal

# Tratar erros na conversão → substitui por NaN
df["coluna"] = pd.to_numeric(df["coluna"], errors="coerce")
```

### ✂️ Remover duplicatas

```python
df = df.drop_duplicates(subset=["coluna"], keep="last")
```

### 🧹 Padronização de texto

```python
df["coluna"] = df["coluna"].str.strip()   # Remove espaços extras
df["coluna"] = df["coluna"].str.title()   # Primeira letra maiúscula
df["coluna"] = df["coluna"].str.upper()   # Tudo maiúsculo
df["coluna"] = df["coluna"].str.lower()   # Tudo minúsculo
df["coluna"] = df["coluna"].str.replace("Python", "Pandas")
```

## 8. Filtragem e Seleção

### Por posição — `iloc`

```python
df.iloc[0]          # Linha 0 completa
df.iloc[0:7, ]      # Linhas 0 a 6
df.iloc[46, 2]      # Linha 46, coluna 2
df.iloc[:, [0,2,5]] # Todas as linhas, colunas 0, 2 e 5
df.iloc[:, 0:3]     # Todas as linhas, colunas 0 a 2
```

### Por rótulo — `loc`

```python
df.loc[0, "Vendas"]      # Linha 0, coluna "Vendas"
df.loc[:, "Vendas"]      # Todas as linhas, coluna "Vendas"
```

### Por condição

```python
# Operadores disponíveis: == > >= < <= != & |
df[df["Vendas"] > 100]
df[df["Cidade"] == "Natal"]
df[df["Cidade"] != "Fortaleza"]

# Múltiplas condições
df[(df["Cidade"] == "Natal") & (df["Vendas"] > 500)]
df[(df["Vendas"] < 50) | (df["Vendas"] > 200)]

# Filtro por ano e mês (com datas)
vendas_mar_19 = df.loc[
    (df["Data"].dt.year == 2019) & (df["Data"].dt.month == 3)
]
```

## 9. Agrupamento e Estatísticas

### Operações básicas

```python

df["Receita"].mean()   # Média
df["Receita"].max()    # Máximo
df["Receita"].min()    # Mínimo

```

### Top N

```python
df.nlargest(3, "Receita")   # 3 maiores receitas
df.nsmallest(3, "Receita")  # 3 menores receitas
```

### Groupby

```python
# Soma por cidade
df.groupby("Cidade")["Receita"].sum()

# Média por marca
df.groupby("Marca")["Tempo_envio"].mean()

# Múltiplas colunas de agrupamento
df.groupby([df["Data"].dt.year, "Marca"])["Lucro"].sum().reset_index()

# Agrupamento com describe
df.groupby("Grupo").describe().T
```

## 10. Manipulação de Datas

> [!IMPORTANT] Fluxo recomendado para tratar datas `object/string` → `int64` → `datetime64`

```python
# Converter para datetime diretamente
df["Data"] = pd.to_datetime(df["Data"])

# Converter com formato específico
df["Data"] = pd.to_datetime(df["Data"], format="%Y-%m-%d")

# Extrair componentes de data
df["Ano"]       = df["Data"].dt.year
df["Mes"]       = df["Data"].dt.month
df["Dia"]       = df["Data"].dt.day
df["Trimestre"] = df["Data"].dt.quarter

# Diferença entre datas (retorna timedelta)
df["Tempo_envio"]     = df["Data Envio"] - df["Data Venda"]

# Converter timedelta para número inteiro de dias
df["Tempo_envio_dias"] = df["Tempo_envio"].dt.days

# Diferença em relação à data mínima
df["Dias_desde_inicio"] = df["Data"] - df["Data"].min()

# Agrupar por ano
df.groupby(df["Data"].dt.year)["Receita"].sum()
```
