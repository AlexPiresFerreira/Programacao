### Series
- "Series" são objetos muito utilizados em análise de dados, As séries mais simples são numéricas, de caracteres ou lógicas
- Ex. 

```
numeros = pd.Series([10,20,30,40,50,60,70,80])

print(numeros)

print(type(numeros))
<class 'pandas.core.series.Series'>
```

- Existem Series que guardam informações de variadas classes:

```
varios = pd.Series([10, 20, 30, "Azul", "Verde", "Vermelho", False, False, True])

print(varios)
```
> Neste caso, a série fica toda identificada como texto

- É possível realizar operações com as séries

### Podemos criar uma variável definida como categórica, isto é, qualitativa


```
tipos = pd.Series(["TipoA", "TipoB", "TipoB", "TipoA", "TipoC", "TipoB"], dtype="category")

print(tipos)

print(tipos)
0    TipoA
1    TipoB
2    TipoB
3    TipoA
4    TipoC
5    TipoB
dtype: category
Categories (3, object): ['TipoA', 'TipoB', 'TipoC']

```

### DataFrame

- DataFrame são os objetos do pandas que guardam informações em bases de dados, Assim, no DataFrame estão contidas colunas (variáveis) e linhas (observações)

```
dataset_1 = pd.DataFrame({'id':["obs_1", "obs_2", "obs_3"],
                          'idade':[60, 28, 53]})

print(dataset_1)
```

- Note que foi criado um objeto do tipo "DataFrame"
- Na função pd.DataFrame as variáveis devem ter o mesmo comprimento

### Importa dados

- Excel
```
Name_variavel = pd.read_excel("arquivo.xlsx")
```

- CSV
```
Name_variavel = pd.read_csv("arquivo.csv", sep=",", decimal=".")
```
>Os argumentos adicionados nesta função foram: O separador (,) e a indicação de decimais (.)

- Link
```

```
>Argumentos: indicação do link, separador das variáveis (;) e decimais (,)
