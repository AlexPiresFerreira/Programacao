## Resumo rápido

- Conversão de tipos é o processo de transformar um valor de um tipo em outro.
- Isso é útil quando precisamos manipular dados de forma diferente da original.

## Quando usar

- Quando um dado vem como `string`, mas precisa ser tratado como número
- Quando precisamos exibir um valor num formato específico
- Quando queremos evitar erros em operações

## Conversões comuns

### `int()` para `float()`


```python
preco = 10
print(preco)

preco = float(preco)
print(preco)

preco = 10 / 2
print(preco)
```

### `float()` para `int()`

```python
preco = 10.30
print(preco)

preco = int(preco)
print(preco)
```

### Número para `str()`

```python
preco = 10.50
idade = 28

print(str(preco))
print(str(idade))

texto = f"idade {idade} preco {preco}"
print(texto)
```

### `str()` para número

```python
preco = "10.50"
idade = "28"

print(float(preco))
print(int(idade))
```

## Conversão por divisão

- Em Python, a divisão `/` retorna `float`

```python
preco = 10
print(preco / 2)
```

## Erro de conversão

- Se a string não representar um número válido, ocorre `ValueError`

```python
preco = "python"
print(float(preco))
```

## Observações importantes

- `int()` remove a parte decimal, sem arredondar matematicamente
- `float()` transforma números em decimais
- Nem toda string pode ser convertida para número
